First Python Game

About
This was my first ever project and the first time I began learning python. I created it in 2024 during my PLC (Post Leaving Certificate) Computer Science course
with help from a friend who introduced me to the basics. Starting with a simple game matched my interest in game development and helped me understand how Python works
especially OOP and how objects behave.

The project remains unfinished because the curriculum later changed to a different language but I'm keeping it here 
as an important milestone in my learning journey.

## What it does
A simple box that moves around the screen using arrow key bindings, built using the Pygame library.

## Tech used
- Python
- Pygame

## What I learned
- Object-oriented programming basics such as creating a Player class that inherits from pygame.sprite.Sprite
- Handling keyboard input with `KEYDOWN` / `KEYUP` events and binding keys
- Using a "movement intent" pattern for smooth continuous movement instead of jerky single-press movement
- Structuring a basic game loop like event handling -> update -> draw -> tick

## Status
🚧 Incomplete / experimental — kept as-is to reflect early learning rather than a finished product.
